## 🌟 Overview

![App Preview Animation](https://media.giphy.com/media/l0HlNaQ6gWfllcjDO/giphy.gif)

**UniSync** is an all-in-one Smart Campus Platform that integrates academic, social, and daily student activities into one intelligent ecosystem.

💡 One platform to manage studies, transport, earnings, and campus life efficiently.

---

## ⚡ Problem Statement  

University students face a fragmented campus experience:

- 📚 Difficulty managing study materials  
- 🔔 Missing important announcements  
- 💸 No trusted earning platform  
- 🚎 Inefficient transport systems  
- 🎉 Missing campus events  
- 🧠 No centralized smart assistant  

---

## 💡 Solution – UniSync  

> 🎯 One Platform. Total Campus Control.

### 📚 Study Buddy & Resource Hub
- AI-powered progress tracking  
- Study recommendations  
- Access to past papers & materials  

### 💰 Student Marketplace & Skills
- Sell notes & study resources  
- Offer tutoring & services  
- Ratings & review system  
- Secure transactions  

### 🚗 Smart Transport System
- Shuttle booking  
- Live tracking  
- Real-time notifications  

### 🎉 Event & Social Matching
- Event recommendations  
- Smart reminders  
- Social connections  

### 🤖 AI Campus Chatbot
- 24/7 support  
- Academic & event assistance  
- Personalized suggestions  

---

## 🧠 Tech Stack  
- Frontend : React.js
- Backend : Node.js + Express.js
- Database : MongoDB Atlas
- Auth : JWT Authentication
- Realtime : Socket.io
- AI : OpenAI API
- Maps : Google Maps API
- Testing : Cypress
- Charts : Chart.js

## ⚙️ Installation

# Clone repository
git clone https://github.com/your-username/unisync.git

# Go into project
cd unisync

# Install frontend
cd client
npm install

# Install backend
cd ../server
npm install

# Run project
npm run dev

---  

## 🔐 Environment Variables

Create a .env file in the server folder:

- MONGO_URI=your_mongodb_uri
- JWT_SECRET=your_secret_key
- OPENAI_API_KEY=your_api_key
- GOOGLE_MAPS_API_KEY=your_key
