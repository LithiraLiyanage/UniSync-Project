## 🌟 Overview

🎓 **Study & Learning Module** is a powerful academic system designed to help university students learn smarter, not harder.

✨ With AI-driven insights, students can:

* 📘 Access modules instantly
* 📄 Find past papers easily
* 📚 Learn with curated resources
* 📊 Track performance visually
* 🤖 Get AI-powered guidance

---

## 🚀 Core Feature – Study & Learning

### 👨‍🎓 Student Dashboard

```
✔ View Modules
✔ Access Past Papers
✔ Study Resources
✔ Track Progress
✔ AI Chat Support
```

💡 Features:

* 📘 Auto module filtering (Year + Semester)
* 📄 Past papers (2020–2025)
* 📚 Resource library
* 📊 Charts (Performance analysis)
* ⚠️ Weak area detection
* 🤖 AI chatbot support

---

### 🧑‍💼 Admin Dashboard

```
✔ Manage Modules
✔ Upload Papers
✔ Add Resources

✔ Monitor Students
```
